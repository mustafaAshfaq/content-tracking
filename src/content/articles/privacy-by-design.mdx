"Privacy by design" gets used as a slogan, but it describes a specific set of
defaults: collect less, ask before collecting more, and make the private
option the one that requires no extra effort.

In practice this means data isn't collected "just in case" it's useful later
— it's collected when there's a concrete, disclosed use for it, and nothing
else. It also means consent is a real choice with a real default of "no,"
not a banner designed to be dismissed without reading.

The test for whether a product actually follows this principle: does turning
every optional data-sharing setting off still leave the core feature working?
